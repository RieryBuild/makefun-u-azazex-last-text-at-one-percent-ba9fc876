A dying phone's final text at one percent battery: instead of saving its last
drop of charge for the morning alarm, it spends it on one petty farewell text —
and leaves its owner to face the morning without it.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
